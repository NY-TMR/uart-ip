## 1. 范围与阅读约定

本文规定可观察的功能、接口、时序及异常行为，是独立功能验证的预期结果依据，不是开发任务清单或测试脚本。原任务书保留为历史需求记录。后续评审已将 RX 重构纳入 v1，并增加 DIV 写入保护及丢失计数；这些行为以本文为准。条目中的 MUST（必须）为验收要求；实现说明用于白盒理解，不要求参考模型复制 RTL。

**时序约定**：T 表示某个 clk 上升沿；T− 表示沿前稳定值，T+ 表示该沿触发的非阻塞赋值及组合传播完成后的值。所有同步事务均依据 T− 条件判定。除低有效异步复位外，内部存储状态仅在 clk 上升沿更新。

**范围内**：TX/RX 独立运行，16 倍节拍分频，相位捕获，单字节等待/接收缓冲，MMIO，RX 电平中断。
**范围外**：AXI/APB 协议适配、多字节 FIFO、RTS/CTS、可配置帧格式、奇偶校验、三点多数表决、帧错误中断、DMA、SoC 中断控制器及软件驱动。当前采用 16 倍节拍定位中心，但每位只采样一次，不等于 16 次多数表决。

## 2. 模块与接口契约

### 2.1 参数

| 名称 | 默认值 | 约束 |
| --- | ---: | --- |
| CLK_FREQ | 100000000 | 正整数，单位 Hz |
| BAUD | 115200 | 正整数，目标波特率 |

复位分频值 D0 = floor(CLK_FREQ / (16 × BAUD))，必须满足 1 ≤ D0 ≤ 65535。参数计算应在 RTL 整数表达式可表示范围内。非法参数组合不属于受支持配置；验证环境必须识别并报告，当前 RTL 未内置参数检查断言，不保证非法配置行为。

### 2.2 端口

| 端口 | 方向 | 位宽 | 语义 |
| --- | --- | ---: | --- |
| clk | input | 1 | 唯一内部工作时钟 |
| rst_n | input | 1 | 低有效异步复位，系统负责安全释放 |
| addr | input | 4 | UART 局部字节地址 |
| wen | input | 1 | 写访问使能 |
| ren | input | 1 | 读访问使能，用于读副作用 |
| wdata | input | 32 | 写入数据 |
| rdata | output | 32 | 组合地址译码读回 |
| rxd | input | 1 | 外部异步串行输入，空闲高 |
| txd | output | 1 | 串行发送输出，空闲高 |
| irq | output | 1 | 高有效 RX 数据待处理中断 |

**IF-01**：每个 rst_n=1 的上升沿可判定一次 MMIO 访问。addr/wdata/wen/ren 由上游满足同步接口时序；连续多个沿有效视为多次访问，并非一次长事务。无 ready/valid 返回、写拒绝响应或读响应寄存器。上游应在消费沿采集沿前 rdata。
**IF-02**：rdata 仅由 addr 和当前寄存器内容组合决定，不受 ren 或 wen 门控；在写访问期间也可用于状态查询。未定义偏移读零、写忽略。仅定义 0x0、0x4、0x8、0xC 四个精确偏移，不做别名或字节使能。
**IF-03**：正常读写由上游发出相应使能；若同时置位 wen/ren，读副作用和写入按各自地址条件独立判定（没有专门的冲突响应）。RXD 写入、STAT 写入无作用，TXD/DIV 读取无副作用。

## 3. 复位契约

**RST-01**：rst_n 拉低后，异步复位生效并经组合传播稳定，无须等待时钟沿。txd=1、irq=0；TX/RX 缓冲为空，RX FSM 为 IDLE，TX busy=0，RX 丢失计数为 0，分频值恢复 D0、分频计数清零。数据缓冲、RX 移位寄存器及索引/相位/节拍计数器清零；TX 移位寄存器全 1。同步链两级均复位为 1。
**RST-02**：复位期间不接受写入、数据消费或有效帧交付；组合读回仍反映所选寄存器的复位状态。复位允许截断在途帧，复位前等待或未读取的数据不自动恢复。
**RST-03**：外部 rxd 在复位释放时可能为低，RX 可在同步后将该低电平作为新的接收尝试；不保证恢复复位之前的半帧。正常通信应先恢复空闲高电平再发送完整新帧。

## 4. MMIO 寄存器映射

寄存器均按 32-bit 读回，未定义位恒为 0；以下位域为软件可见契约。

| 偏移 | 名称 | 位域 | 访问 | 描述 |
| --- | --- | --- | --- | --- |
| 0x0 | TXD | [7:0] | W | 待发送字节；接受条件见 TX-01 |
| 0x0 | TXD | [0] | R | TX_FULL，等待槽占用 |
| 0x4 | RXD | [7:0] | R | RX_DATA，最近一次有效接收数据 |
| 0x4 | RXD | [8] | R | RX_FULL，沿前数据是否有效 |
| 0x4 | RXD | [11:9] | R | RX_LOST_CNT，饱和丢失计数 |
| 0x8 | STAT | [0] | R | TX_FULL |
| 0x8 | STAT | [1] | R | TX_BUSY |
| 0x8 | STAT | [2] | R | RX_FULL（兼容旧 RX_VALID） |
| 0x8 | STAT | [3] | R | RX_OVERRUN，RX_LOST_CNT 非零 |
| 0x8 | STAT | [6:4] | R | RX_LOST_CNT |
| 0xC | DIV | [15:0] | R/W | 当前生效分频值 |

```text
RXD  [31:12] reserved | [11:9] LOST_CNT | [8] FULL | [7:0] DATA
STAT [31:7]  reserved | [6:4]  LOST_CNT | [3] OVR | [2] RXF | [1] TXB | [0] TXF
```

**REG-01**：有效 RXD 读取具有消费副作用（见 RXB-02），STAT 读取无副作用；RXD 中同时返回数据、有效标志和丢失计数的沿前快照。
**REG-02**：RX_FULL=0 时，RXD 的数据域为保留的最近一次接收值（复位后为零），不代表新数据。读空不消费未来到达的数据。
**REG-03**：新增位域占用旧版保留位，原有效字段位置不变；旧软件必须按位掩码解析，不保证依赖整字保留位为零的软件兼容。保留 TXD[0] 无需 ren 的读回行为。

## 5. 分频与共享资源

设 D 为当前生效的 DIV，Tclk=1/CLK_FREQ。

- 过采样节拍间隔：D 个 clk 周期。
- 本地位周期：16D 个 clk 周期；本地实际波特率为 CLK_FREQ/(16D)。
- 默认 D=54，每位 864 个 clk 周期，8N1 帧长 8640 个 clk 周期（不含帧间空闲）。
- 50 MHz / 115200 配置 D=27，每位 432 个 clk 周期。

**DIV-01**：自由运行的分频计数器范围为 0 至 D−1（含）。终值沿归零，否则加一；合法 DIV 写入沿同样同步清零计数器。D=1 时终值条件可持续为高，每个 clk 沿均是节拍。
**DIV-02**：仅在以下所有沿前条件同时成立时接受 DIV 写入：rst_n=1、wen=1、addr=0xC、TX_BUSY=0、TX_FULL=0、RX 状态为 IDLE、同步后的 rxd 为高、wdata[15:0] 非零。高 16 位忽略。
**DIV-03**：其余写入拒绝且不排队；DIV 保持原值、分频计数器正常运行（自然终值回绕仍允许）。合法重复写入相同值也重启计数器。
**DIV-04**：RX 从开始起始位校验到停止位采样完成期间禁止修改 DIV。IDLE 且同步输入为低时，RX 启动优先于同沿 DIV 写入。TX 等待槽非空或正在发送时也禁止修改。
**DIV-05**：TX 和 RX 在各自启动沿独立捕获共享计数器的沿前相位，在各自活动期间每隔 D 个系统周期获得一次有效过采样节拍，首个有效节拍在启动后 D 个周期。一个方向的启动、完成不得重置共享计数器或扰乱另一个方向的节拍。
**DIV-06**：原始异步 rxd 尚未传播至同步器输出时，DIV 保护无法感知外部即将开始的帧；软件应在双方停止通信时修改波特率。接收完成定义在停止位中心，而非完整停止位末尾。

## 6. TX 功能与精确时序

### 6.1 等待槽

TX 有一个待发字节槽和一个在途帧；TX_FULL 与 TX_BUSY 各自独立，允许同时为 1。

**TX-01**：复位释放后，wen=1、addr=0x0 且沿前 TX_FULL=0 时，接受 wdata[7:0] 并置位 TX_FULL。其余 TXD 写入忽略。
**TX-02**：若沿前 TX_FULL=1 且 TX_BUSY=0，则在该沿启动该字节的发送，清 TX_FULL、置 TX_BUSY，并输出低电平起始位。刚入队的字节最早在下一沿启动；即使同沿取走原字节，沿前槽满仍拒绝新写入（无满槽同沿替换）。
**TX-03**：发送过程中允许在空等待槽中存入一个新字节，不改变在途帧；已接受且未复位丢弃的字节按接受顺序发送。

### 6.2 发送帧

**TX-04**：8N1，空闲 1，起始位 0，D0～D7（LSB first），停止位 1。设启动沿为 S，位周期 P=16D 个 clk：

| 相对 S 的周期区间（左闭右开） | txd |
| --- | --- |
| [0, P) | 0（START） |
| [(i+1)P, (i+2)P)，i=0..7 | 数据 bit i |
| [9P, 10P) | 1（STOP） |
| 10P 之后，未启动新帧 | 1（IDLE） |

相邻相同电平的位不一定产生线路跳变，但逻辑位时间仍为 P。首位长度不得随启动时的自由运行计数器相位变化。

**TX-05**：S+10P 沿完成停止位并清 TX_BUSY。若等待槽已有下一字节，最早 S+10P+1 沿启动下一帧，因此允许至少一个 clk 的帧间空闲。完成沿本身不同时启动下一帧。
**TX-06**：复位中止当前帧及等待字节；空闲输出始终为高。无额外 TX 完成中断。

## 7. RX 功能与精确时序

### 7.1 CDC 与启动

**RX-01**：rxd 经两级 clk 同步器进入接收控制逻辑。两级每个系统时钟沿更新，不受 baud tick 限制；复位均为高。接收控制仅使用第二级输出。双触发器降低亚稳态传播概率，不保证消除；数字仿真不能证明物理 MTBF。
**RX-02**：RX_IDLE 状态检测同步输入为低即在对应上升沿启动候选帧，捕获分频相位，清采样节拍计数；不要求同步下降沿，也不受 RX_FULL 限制。

### 7.2 状态机契约

| 当前状态 | 事件/条件（沿前） | 下一状态 | 同沿行为 |
| --- | --- | --- | --- |
| IDLE | 同步输入为低 | START | 捕获相位，建立计数起点 |
| START | 半位采样且输入为高 | IDLE | 拒绝候选帧 |
| START | 半位采样且输入为低 | DATA | 确认起始位 |
| DATA | 数据位采样，索引 0..6 | DATA | 保存该位，索引递增 |
| DATA | 数据位采样，索引 7 | STOP | 保存 D7，结束数据采样 |
| STOP | 停止位采样 | IDLE | 高则交付有效字节，低则丢弃 |
| 任意 | 不满足以上事件 | 原状态 | 无相应采样或状态转移 |

**RX-03**：START 校验期间不属于已确认的接收阶段；DATA/STOP 属于已确认接收阶段。当前 RTL 不单独实现或暴露 rx_busy 寄存器；共享 DIV 的保护范围包括 START。
**RX-04**：设候选帧启动沿为 R，以 clk 周期计，在 R+8D 采样起始位中心；若通过，则在下表各沿采样。首次数据位采样与起始位确认之间必须间隔完整 16D 周期，不得只间隔 8D。

| 对象 | 距 R 的过采样节拍 | 距 R 的 clk 周期 |
| --- | ---: | --- |
| START | 8 | 8D |
| D0 | 24 | 24D |
| D1 | 40 | 40D |
| D2 | 56 | 56D |
| D3 | 72 | 72D |
| D4 | 88 | 88D |
| D5 | 104 | 104D |
| D6 | 120 | 120D |
| D7 | 136 | 136D |
| STOP | 152 | 152D |

**RX-05**：仅 DATA 状态执行八次串并转换；最终并行字节 bit i 等于第 i 次数据采样值。停止位采样为 1 才可交付缓冲区；为 0 必须退出本次接收并丢弃字节。START 校验失败不得产生数据交付。
**RX-06**：持续低电平可反复触发候选接收，但只要停止位采样为低，不得交付有效字节。无独立 break/帧错误标志或错误计数。噪声若恰好满足中心采样条件仍可能被视为帧；不保证任意干扰或任意波特率偏差下正确接收。
**RX-07**：相位表以同步后的候选启动沿为基准，不以原始 rxd 物理边沿为基准。验证外部激励时应考虑同步延迟及位周期差。支持正常连续 8N1 帧（停止位后可立即跟下一起始位）；接收误差容限需通过独立验证评估，本文不承诺未经测量的具体容限百分比。

## 8. RX 数据交付与溢出

接收器与 CPU 通过单字节接收缓冲解耦。缓冲已满也不能向外部发送端反压，采用 Overwrite Old。

定义沿前事务：
- V：本沿在 STOP 状态进行停止位中心采样且采样为高（有效新字节交付）。
- Q：rst_n=1、ren=1、addr=0x4（RXD 读请求）。
- F：RX_FULL 沿前值。
- C=Q 且 F（有效消费）；L=V 且 F 且非 C（发生旧字节丢失）。

**RXB-01**：V 成立时缓冲更新为新字节且 RX_FULL 置 1；若沿前已满且未消费，则覆盖旧字节并增加丢失计数。无 V 时缓冲内容保持（复位除外）。
**RXB-02**：有效消费清除 RX_FULL 及丢失计数，但若同沿 V 成立，RX_FULL 仍为 1；CPU 在该沿取得旧数据及其沿前状态，新字节留待下一次读取。空读不消耗新字节、不做组合旁路。仅有效消费具有清除计数副作用。
**RXB-03**：丢失计数 3 bit，复位或有效消费清零；L 成立时饱和加一，最大值 7 表示至少丢失 7 个字节。仅统计被覆盖的有效旧字节，不统计错误帧、空读或复位丢弃。OVERRUN 为计数非零的组合状态。
**RXB-04**：下表穷举非复位沿的缓冲仲裁。A 为原缓冲内容，B 为新有效字节，n 为沿前丢失计数。

| F | Q | V | 本沿 CPU 有效消费 | 沿后数据 | 沿后 FULL | 沿后计数 |
| ---: | ---: | ---: | --- | --- | ---: | --- |
| 0 | 0 | 0 | 否 | A | 0 | n |
| 0 | 0 | 1 | 否 | B | 1 | n |
| 0 | 1 | 0 | 否 | A | 0 | n |
| 0 | 1 | 1 | 否 | B | 1 | n |
| 1 | 0 | 0 | 否 | A | 1 | n |
| 1 | 0 | 1 | 否 | B | 1 | min(n+1,7) |
| 1 | 1 | 0 | A | A | 0 | 0 |
| 1 | 1 | 1 | A | B | 1 | 0 |

复位优先于表中全部事件。正常可达状态满足 RX_FULL=0 时丢失计数为 0。

## 9. IRQ 契约

**IRQ-01**：高有效电平型中断，irq 恒等于 RX_FULL，不是单周期脉冲；不设独立使能、屏蔽或挂起寄存器。
**IRQ-02**：有效字节到达后拉高，保持到最后一个待消费字节被读取或复位。有效消费与新帧交付同沿时保持高，不应强制产生低脉冲。错误帧不产生新的中断，但也不能撤销已有待消费数据的中断。
**IRQ-03**：读 STAT 不清中断；OVERRUN 不单独触发中断。外部中断响应、优先级和 ISR 属于 SoC。

## 10. 微架构与白盒观察指南（非额外接口）

```text
                        shared baud_divisor / baud_clk_cnt
                           |                          |
                    tx_start_phase             rx_start_phase
                           |                          |
MMIO write -> tx_buf -> tx_shift -> txd      rxd -> synchronizer
                |           |                        |
             tx_full     tx_busy          FSM + tick/index counters
                                                     |
                                                  rx_shift
                                                     |
                                             rx_buf / rx_full
                                                     |
                               MMIO read <- read mux + lost_cnt -> irq*
```

* irq 实际仅由 rx_full 驱动，不由 lost_cnt 驱动。

| RTL 观察点 | 职责 |
| --- | --- |
| tx_push / tx_start / tx_step / tx_done | TX 接受、启动、移位、结束事件 |
| tx_tick_cnt / tx_bit_idx | TX 过采样计数、帧位索引 |
| rxd_meta / rxd_sync | 两级同步 |
| rx_state / rx_next_state | 二段式 RX FSM |
| rx_start / rx_start_phase / rx_baud_tick | RX 启动、独立相位与节拍条件 |
| rx_tick_cnt / rx_half_tick / rx_bit_tick | 半位及整位采样时序 |
| rx_bit_idx / rx_shift | 数据位索引与串并转换 |
| rx_frame_valid / rx_pop / rx_overrun | 有效帧交付、消费、丢失事件 |
| rx_buf / rx_full / rx_lost_cnt | 可见数据及状态 |

注意：内部 rx_overrun 是单沿丢失事件；软件可见 STAT.OVR 是粘滞意义的计数非零状态。baud_tick、tx_baud_tick、rx_baud_tick 为组合条件，不是派生时钟；在复位、空闲或 D=1 下不要求它们表现为孤立脉冲。只有结合状态和 clk 沿解释才构成操作事件。

## 11. 验证接口与验收原则

本节给出需求追踪范围和交付标准，不代替验证计划。验证人员应独立选择激励、参考模型、检查器、断言及覆盖点，并解释每一项如何证明规格成立。

| 需求组 | 需要证明的能力 |
| --- | --- |
| IF / REG | 接口时序、位域与保留位、无副作用读取、读后消费 |
| RST | 空闲与活动过程中复位、无残留事务 |
| DIV | 参数合法性、动态重配置、共享资源保护、相位独立性 |
| TX | 数据顺序、帧格式、精确位周期、缓冲容量与拒绝条件 |
| RX | 同步后的启动与采样时序、位序、连续帧及异常帧 |
| RXB | 缓冲仲裁、溢出计数、饱和及清除行为 |
| IRQ | 中断电平与有效数据状态一致 |

建议验收产物包含：需求 ID 到验证项的追踪矩阵、可重复执行的仿真命令与环境配置、自动判定的 PASS/FAIL 结果、失败波形及原因、覆盖结果与未覆盖风险。不能用单次波形目测或仅 TX/RX loopback 代替独立参考验证：相同实现错误可能在环回中互相抵消。CDC 和复位释放还应进行结构/约束审查，不能仅凭 RTL 仿真宣称无亚稳态。

## 12. 兼容范围与待验事项

- 模块名、参数及端口保持不变；原寄存器地址与已有位域保留。新增丢失计数占用保留位。
- 相比初始任务书，RX 已重新设计、停止位错误帧被拒绝、DIV 增加 RX 占用及启动保护；这些是规格变更而非完全等同行为。
- 原 SoC 的部分 UART 实例可能仅连接 TX，接收线、MMIO 读使能及中断连接需在系统集成时检查。独立 IP 验收与系统级接收/中断验收分开。
- 本文发布时 RTL 已实现功能路径，但尚未执行完整仿真、CDC/STA 或软件回归，未声明通过验收；后续发现规格歧义或实现缺陷应单独记录并评审，不得仅为使测试通过而修改预期行为。
